# mini-rag

This is a minimal implementation of the RAG model for question answering.

## Requirements

-Python 3.8 or later

### Install Python using MiniConda

1) Download and install MiniConda from [here]<https://www.anaconda.com/docs/getting-started/concepts/anaconda-or-miniconda#quick-command-line-interface>

1) Create a new environment using the following command:

```bash
conda create -n mini-rag-app python=3.8
```

1) Activate the environment:

```bash
conda activate mini-rag-app
```

### (optional) setup you command line interface for better readability

```bash
export PS1="\[\033[01;32m\]\u@\h:\w\n\[\033[00m\]\$"
```
